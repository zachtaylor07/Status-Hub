District Tech Team Implementation Note

How This Centralized Status Hub Gathers Vendor Feeds

In modern district architecture, each of these vendors exposes public status feeds via Atlassian Statuspage APIs, Instatus endpoints, RSS/Atom feeds, or direct JSON feeds. Because web browsers enforce Cross-Origin Resource Sharing (CORS) when client-side browsers query 3rd-party status domains directly, this dashboard provides both direct status page linkouts and automated telemetry simulation with fallback to public JSON endpoints.

To run live polling in production on your school district intranet without CORS blocking, you can deploy a lightweight Cloudflare Worker or AWS Lambda function that queries the standardized vendor endpoints every 60 seconds:

// Example status endpoints supported in this dashboard:
• Canvas: https://status.instructure.com/api/v2/status.json
• Google Classroom: https://www.google.com/appsstatus/dashboard/incidents.json
• ClassLink: https://status.classlink.com/api/v2/summary.json
• NWEA: https://status.nwea.org/api/v2/status.json
• Book Creator: https://status.bookcreator.com/api/v2/status.json
• Infinite Campus: https://status.infinitecampus.com/api/v2/summary.json
