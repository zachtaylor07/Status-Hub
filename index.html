District Tech Team Implementation Note

How This Centralized Status Hub Gathers Vendor Feeds

In modern school district architectures, each of these 15 vendors publishes public status feeds via Atlassian Statuspage APIs, Instatus endpoints, RSS/Atom, or direct status dashboards. To run scheduled background polling on a district intranet without CORS blocking, IT teams can relay these endpoints through a lightweight edge proxy or Cloudflare Worker.

Supported vendor status API endpoint formats for district network polling:

• Canvas: https://status.instructure.com/api/v2/status.json
• Google Workspace: https://www.google.com/appsstatus/dashboard/incidents.json
• ClassLink: https://status.classlink.com/api/v2/status.json
• Frontline: https://status.frontlineeducation.com/api/v2/status.json
• GoGuardian: https://status.goguardian.com/api/v2/status.json
• Amplify: https://status.amplify.com/api/v2/status.json
• NWEA: https://status.nwea.org/api/v2/status.json
• Book Creator: https://status.bookcreator.com/api/v2/status.json
• Infinite Campus: https://status.infinitecampus.com/api/v2/summary.json
• Finalsite: https://status.finalsite.com/api/v2/status.json
• Progress Learning: https://status.progresslearning.com/api/v2/status.json
